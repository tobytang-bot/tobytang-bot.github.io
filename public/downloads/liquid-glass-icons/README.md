# Liquid Glass SVG Icon Pack

风格：黑色 Liquid Glass / 蓝紫霓虹高光
格式：SVG（可直接用于前端）

包含：
- 8 个纯箭头：arrow-left/right/up/down/up-right/down-right/down-left/up-left
- 4 个圆形按钮箭头：circle-arrow-left/right/up/down
- 4 个圆角方形按钮箭头：square-chevron-left/right/up/down

使用建议：
1. 直接作为 `<img src="...svg">` 使用
2. 或内联到 HTML 里，方便改尺寸与 hover 动画
3. 推荐配合深色背景展示效果更明显
